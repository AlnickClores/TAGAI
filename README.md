# Tagai

A rule-based AI bartender web app that recommends popular Filipino drinks and mixes based on user preferences.

---

## Live Demo
[https://tagaiapp.vercel.app/](https://tagaiapp.vercel.app/)

Deployed using **Vercel**.

## Description

**Tagai** Tagai is a rule-based bartender web application designed to help users decide what alcoholic drink to enjoy. It generates drink recommendations using predefined rules that match user preferences such as mood, budget, alcohol level, flavor profile, and drink type (mixed or ready-to-drink).

The goal of this project is to simplify the process of choosing alcoholic drinks while showcasing the implementation of a rule-based recommendation system in a modern frontend application.

## Key Features
- Suggests alcoholic drinks based on user preferences
- Includes drink details such as ingridients and steps for mix drinks
- Recommends drinks that are commonly available in the Philippines
- Filter drinks by mood, budget, alcohol level, mix or ready-to-drink, and flavor

## Tech Stack
-  React
-  Vite
-  TypeScript
-  TailwindCSS

## Usage

1. Select your preferred drink type (Ready-to-Drink or Mix).
2. Choose your mood and flavor preferences (multiple selections allowed).
3. Select your desired alcohol level.
4. Set your preferred budget range.
5. Click Get My Drink to receive your recommended drinks.
