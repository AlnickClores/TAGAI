<h1 align="left">Tagai</h1>

<p align="left">
An AI powered bartender web app that recommends popular Filipino drinks and mixes based on user preferences.
</p>

## ✨ Features

- 🧠 **AI-Powered Drink Recommendations**: Suggests drinks based on user preferences and rules
- 🍹 **Customized Choices**: Filter drinks by mood, budget, alcohol level, mix vs. ready-to-drink, and flavor
- 🇵🇭 **Philippines-Focused Menu**: Recommends drinks that are commonly available in the Philippines
- 📅 **Interview Scheduling**: Keep track of interview dates
- 📊 **Preference Insights**: Learn which types of drinks you prefer based on your selections
